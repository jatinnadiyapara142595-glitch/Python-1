📘 Python List Operations
📌 Description

This program demonstrates various operations performed on Python lists.
It covers basic list manipulation techniques commonly used in Python programming.

📝 Lists Used
list1 = ['physics', 'chemistry', 1997, 2000]
list2 = [1, 2, 3, 4, 5, 6, 7]

🔧 Operations Implemented

List Concatenation

Remove element from list

Add element using append()

Update list element

Delete element using del

Print statement multiple times

Slicing operations

Find length using len()

Find maximum and minimum elements

Use append() and extend()

Difference between pop() and remove()

Reverse list using reverse()

Sort list in descending order

💡 Concepts Used

Python Lists

List Methods

Loops

Built-in Functions

▶️ How to Run

Make sure Python is installed (Python 3 recommended).

Save the file as list_operations.py.

Run the following command:

python list_operations.py

This program is created for educational and practical understanding of list operations in Python
